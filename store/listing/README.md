# Play Store listing copy

Source-of-truth copy for the Play Store (and any future App Store / web)
listing, in English and Italian.

## Files

- `en/short_description.txt` — Play Store short description, ≤ 80 chars
- `en/long_description.txt`  — Play Store long description (paste into the listing as-is)
- `it/short_description.txt` — Italian short description
- `it/long_description.txt`  — Italian long description

## App name

- Surface name (icon label / Play Store title): **Scopa Score**
- Italian surface name: **Scopa — Segnapunti**

These are wired into `index.html`, `capacitor.config.ts`, `public/manifest.webmanifest`, `src/i18n.ts`, and the Android `strings.xml` — keep all five in sync when changing.

## Feature graphic tagline

- EN: *"Score Scopa effortlessly"*
- IT: *"Tenere il punteggio Scopa senza fatica"*

## Screenshots

Generated by `npm run screenshots` (see `scripts/screenshots.mjs`). Output lands in `store/screenshots/en/` and `store/screenshots/it/`. Re-run after any UI change before publishing.

## Caveats from the listing copy

A few claims in the long description depend on already-merged feature work:

- **"Real statistics"** (head-to-head, win streaks, category breakdowns) — landed in #44
- **"Quick start"** (recent groupings + favorites) — landed in #55
- **"No tracking, no analytics"** — depends on #56's decision to ship without analytics

If any of those positions change, update the copy here before publishing.
